# Tower of Babylon

A multiplayer survival horror game show: condemned contestants climb an endless tower while the galaxy watches.
C99 + raylib, built for the browser (WebAssembly) and Android.

- Android: Actions tab, "Android APK", Run workflow. See docs/android.md.
- Tests: bash tools/run_tests.sh. See docs/testing.md.
- Repo and update flow: docs/repo.md. The game plan: docs/design/.
